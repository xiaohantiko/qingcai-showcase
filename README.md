# 清财 · Qingcai for Mac

清财是面向中国大陆小型公司的原生 macOS 财务工作台。你可以在同一个应用里记录收支和往来、归档凭证、跟踪报销与工资、核对银行流水，以及查看税务测算和月末报表。

## 下载安装

公开安装包适用于 **Apple 芯片 Mac，macOS 14 或更新版本**。

1. 在发布页下载 `Qingcai-macOS-arm64.zip`。 [最新公开版本和 SHA-256 校验文件](https://github.com/xiaohantiko/qingcai-showcase/releases/latest)
2. 解压后将「清财公开版.app」拖入「应用程序」，然后打开。当前下载包的签名与公证状态见对应发布说明。

## 第一次使用

1. **先体验演示账本。** 点击左栏底部的「体验演示账本」，即可用虚构账目查看财务概览、报表和记账流程。演示修改只保存在本次会话中。
2. **建立自己的账本。** 退出演示后，打开「公司与备份」，填写公司名称、注册地、期初资金和适用的纳税配置，再点「确认并保存公司设置」。
3. **录入第一笔业务。** 点击「记一笔」，按实际情况填写业务归属日、收付款日和含税金额，并可归档 PDF 或图片凭证。批量录入时，在「收支与往来 → 导入 / 导出」下载 CSV 模板，填写后再导入。
4. **对账并查看结果。** 在「银行对账」导入银行流水 CSV 并核销对应账目。在「报表与结账」查看汇总和月末检查，确认后结账。

「报销审批」「工资与社保」「固定资产」「会计总账」分别管理报销、工资和缴费、直线折旧及手工借贷凭证。「税务中心」按公司配置估算税额，申报和缴款完成后可在「流程与提醒」登记回执及凭证。

## 试用接口流程

打开「接口与自动化 → 测试与接口 → 启动测试环境」。内置网关在 Mac 上运行，可同步虚构银行流水，或创建模拟开票、申报与缴税草稿。到「任务与回执」核对并确认草稿，随后查看处理状态和模拟回执。模拟回执仅供演示。真实机构办理需要自行部署兼容网关、取得机构授权并完成联调。 [公开网关协议](gateway/openapi.json)

## 数据与备份

公开版账本和附件保存在独立的本机应用数据目录。在「公司与备份」可导出完整备份、恢复备份，或选择云盘文件夹保存备份副本。移动导出的备份时，请将备份文件和同级的 `Attachments` 文件夹一起保留。

## 从源码构建

需要 Xcode 命令行工具。下列命令会构建原生应用并执行财务与网关检查。

```bash
bash scripts/build-app.sh
swift run --build-system native QingcaiChecks
open 'dist/清财公开版.app'
```
